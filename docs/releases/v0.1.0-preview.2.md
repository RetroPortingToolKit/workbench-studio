This fixes multiplayer games showing only player 1 in the generated launcher.

Studio now reads the disc's boot serial and gets the player count from matching kit metadata or a serial-based catalogue lookup. Trap Gunner is recognised as a two-player game, including its USA, Japanese and PAL releases. Single-player games keep one player. There is no player-count selector or blanket two-player default.

Rebuild affected games with this version, then assign separate controllers in the generated launcher's player tabs. Existing game folders are not changed. Games with more than two players still need their own multitap support and the launcher multitap option.

The first lookup for an uncatalogued serial needs an internet connection. Successful lookups are cached. If the serial or player metadata cannot be identified, Studio reports the problem before building instead of silently choosing one player. The small bundled catalogue covers Trap Gunner's three regional serials and Crash Bandicoot USA; it is not a complete offline game database. Metadata comes from [PSX Data Center](https://psxdatacenter.com/).

Checked: serial identification from authored disc images, kit metadata precedence, single-player and multiplayer configuration, lookup caching and failures, the Windows frontend build, package contents and hidden frontend rendering. Trap Gunner's controller-slot regression uses authored test media with its verified serial; we did not compile or play a retail Trap Gunner disc, or test two physical controllers together.
