This fixes Bust A Groove's player-count lookup and adds a manual recovery option.

Each game card now has **Players: Auto / 1–8**. Auto remains the default. If metadata cannot be read, the game stays in the list so you can choose its supported count and build. An explicit override takes priority for that build, is recorded as manual, and does not replace the automatic metadata cache.

Bust A Groove's page contains zero-padded text that the previous reader mishandled. The corrected reader identifies the USA disc as two-player. The lookup also reads the multitap limit: some pages list two standard controllers and a higher player count in a separate field. Older cached counts are refreshed.

Read-only detection checks passed on our actual images of Bust A Groove and Tekken 3 (two players), Crash Warped and Spyro (one player), Poy Poy (four players), and Devil Dice (five players). Their verified counts are also bundled for offline lookup. No game was recompiled or started for these checks. These are serial/metadata checks, not proof of gameplay or simultaneous physical-controller input.

Extract the complete ZIP and open `Workbench Studio.cmd`. Rebuild affected game projects when you want the corrected count in their generated launchers. Games with more than two players still need their own multitap support and the launcher multitap option. Choosing a higher count does not add multiplayer to a single-player game.

The supported core and launcher versions are unchanged. The attached checksum belongs to this release's ZIP. See [PSX Data Center](https://psxdatacenter.com/) for the source metadata.
